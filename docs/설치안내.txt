Climb My Own — 폰에 설치하기
================================

주소
  https://cjygod-arch.github.io/climb-my-own/


■ 안드로이드 (크롬)

  1. 크롬으로 위 주소를 엽니다.
     ※ 삼성 인터넷·네이버앱 등 다른 브라우저 말고 크롬으로 여세요.

  2. 우측 상단 ⋮ → 스크롤을 내려 [앱 설치] 또는 [홈 화면에 추가]
     또는 앱 안에서 내 정보 → 앱으로 설치하기 → 설치

  3. 홈 화면에 파란 산 아이콘이 생깁니다.


■ 아이폰 (사파리)

  반드시 사파리로 열어야 합니다. 다른 브라우저에서는 홈 화면 추가가 안 됩니다.

  1. 사파리로 주소를 엽니다.
  2. 아래 공유 버튼(⬆) → [홈 화면에 추가]
  3. 이름을 확인하고 [추가]


■ 보안 설정은 건드리지 않아도 됩니다

  이 앱은 APK가 아니라 브라우저가 설치하는 웹앱(PWA)입니다.
  "출처를 알 수 없는 앱" 허용이나 보안위험 자동차단 해제 같은 절차가
  필요 없습니다. 그런 안내가 보이면 잘못된 것이니 따르지 마세요.


■ 설치 후 확인할 것

  아이콘        파란 배경에 흰 산 모양
  실행          주소창 없이 전체화면
  위치 권한     안내·걷기 시작 시 한 번 물어봄 → 허용
  오프라인      비행기 모드에서도 앱이 뜨고 명산 목록이 보임
  길게 누르기   바로가기 2개 (운동(걷기) 기록 / 100대 명산)


■ 지금 상태에서 알아두어야 할 것

  · 로그인은 개발용입니다.
    Supabase를 아직 연결하지 않아 아무 버튼이나 눌러도 들어가지고,
    기록은 그 폰에만 남습니다.
    실제 계정 연동은 supabase/README.md 절차를 따르면 됩니다.

  · 산 데이터는 20/100곳입니다. 코스는 61개이고
    그중 39개만 실제 등산로 경로이며, 나머지는 "개략 경로"로 표시됩니다.

  · 화면이 꺼지면 위치 갱신이 느려지거나 멈춥니다.
    긴 산행을 기록할 때는 화면을 켜두거나 절전 모드를 끄세요.
    웹앱의 구조적 한계이며, 브라우저가 백그라운드 추적을 허용하지 않습니다.

  · 지도 타일은 캐시하지 않습니다. 오프라인에서는 이미 본 화면만 뜹니다.


■ 코드를 고친 뒤

  git add -A
  git commit -m "설명"
  git push

  push만 하면 CI가 import 경로·시드 데이터·아키텍처 규칙을 검사한 뒤
  자동 배포합니다. 검사에 실패하면 배포되지 않습니다.

  배포 상황은 저장소의 Actions 탭에서 볼 수 있습니다.


■ 고쳤는데 폰에서 안 바뀐다면

  1. 앱을 완전히 닫았다가 다시 엽니다.
  2. 그래도 남아 있으면 sw.js 의 VERSION 값을 올립니다 (v1 → v2).
  3. 최후: 홈 화면 아이콘을 지우고 브라우저에서 다시 설치합니다.


자세한 내용은 docs/INSTALL.md 를 보세요.
