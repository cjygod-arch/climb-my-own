# 폰에 설치하기

이 앱은 **PWA**다. 앱스토어를 거치지 않고 브라우저에서 홈 화면에 추가하면
아이콘이 생기고 주소창 없이 전체화면으로 실행된다.

---

## 먼저 알아야 할 것: HTTPS가 필요하다

브라우저는 아래 세 가지를 **보안 컨텍스트에서만** 허용한다.

| 기능 | HTTPS 필요 |
|---|---|
| 위치(GPS) — 산행 안내·걷기 기록 | **필수** |
| 홈 화면 설치 | **필수** |
| 오프라인(서비스 워커) | **필수** |

`localhost`는 예외로 허용되지만, **폰에서 `http://192.168.0.x:5173` 으로 접속하면
전부 막힌다.** 우회할 방법은 없다 — 브라우저 규칙이다.

그래서 폰 테스트는 아래 둘 중 하나로 한다.

---

## 배포는 이미 되어 있다

**https://cjygod-arch.github.io/climb-my-own/**

폰 브라우저에서 이 주소를 열면 된다. HTTPS라 위치·설치·오프라인이 모두 동작한다.

코드를 고친 뒤에는 push만 하면 CI가 검사하고 자동 배포한다.

```bash
git add -A
git commit -m "설명"
git push
```

배포 상황은 저장소의 **Actions** 탭에서 볼 수 있다.

## 배포 없이 즉시 확인하고 싶다면 (선택)

내 PC의 개발 서버를 임시 HTTPS 주소로 열어준다. 배포 없이 즉시 확인할 수 있다.

```bash
# 1) 개발 서버를 띄운 채로 두고
node tools/dev-server.mjs

# 2) 다른 터미널에서 (설치 필요: cloudflared)
cloudflared tunnel --url http://localhost:5173
```

출력되는 `https://<임의문자>.trycloudflare.com` 주소를 폰에서 연다.
터미널을 닫으면 주소도 사라진다.

> Supabase를 연결했다면 이 임시 주소도
> **Authentication → URL Configuration → Redirect URLs** 에 추가해야 로그인이 돌아온다.

## 설치 방법

### 안드로이드 (크롬)

1. 위 HTTPS 주소를 크롬으로 연다
2. 잠시 뒤 **내 정보 → 앱으로 설치하기 → 설치** 를 누른다
   - 또는 크롬 우측 상단 `⋮` → **앱 설치**

### 아이폰 (사파리)

**반드시 사파리로 열어야 한다.** 크롬·네이버앱 등 다른 브라우저에서는 홈 화면 추가가 안 된다.

1. 사파리로 주소를 연다
2. 아래 **공유 버튼**(⬆️) → **홈 화면에 추가**
3. 이름을 확인하고 **추가**

---

## 설치 후 확인할 것

| 항목 | 정상 동작 |
|---|---|
| 아이콘 | 파란 배경에 흰 산 모양 |
| 실행 | 주소창 없이 전체화면 |
| 위치 권한 | 안내·걷기 시작 시 한 번 물어봄 → **허용** |
| 오프라인 | 비행기 모드에서도 앱이 뜨고 명산 목록이 보임 |
| 홈 화면 길게 누르기 | 바로가기 2개 (운동(걷기) 기록 / 100대 명산) |

## 코드를 고쳤는데 폰에서 안 바뀐다면

서비스 워커는 **network-first**로 잡아두어서, 연결만 되면 항상 새 파일을 받는다.
그래도 남아 있다면:

1. 앱을 완전히 닫았다가 다시 연다 (새 워커가 제어권을 가져가며 자동 새로고침한다)
2. 그래도 안 되면 `sw.js` 의 `VERSION` 값을 올린다 (`v1` → `v2`). 옛 캐시가 통째로 지워진다
3. 최후: 홈 화면 아이콘을 지우고 브라우저에서 다시 설치

## 알아두어야 할 한계

- **화면이 꺼지면 위치 갱신이 느려지거나 멈춘다.** 웹앱의 구조적 한계다.
  긴 산행을 기록할 때는 화면을 켜두거나 절전 모드를 꺼야 한다.
  네이티브 앱처럼 백그라운드에서 계속 추적하는 것은 브라우저가 허용하지 않는다.
- **iOS는 PWA 제약이 더 많다.** 백그라운드 위치, 푸시 알림 등이 안드로이드보다 제한적이다.
- **오프라인은 '이미 본 것'만 된다.** 지도 타일은 캐시하지 않는다 —
  하면 저장 용량이 순식간에 불어나기 때문이다. 산에서 지도를 보려면
  미리 해당 지역을 열어두거나 별도 지도 앱을 함께 쓴다.

백그라운드 추적이 꼭 필요하다면 그때는 네이티브 껍데기(Capacitor 등)를 씌워야 한다.
지금 구조에서는 화면 코드를 그대로 두고 껍데기만 추가하면 된다.

## 아이콘을 바꾸려면

```bash
# 1) icons/icon.svg 를 고친 뒤
# 2) Chrome을 디버깅 포트로 띄우고
"C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" \
  --headless=new --remote-debugging-port=9333 --user-data-dir=/tmp/cicon about:blank

# 3) 다시 굽는다
node tools/build-icons.mjs
```

이미지 라이브러리를 따로 들이지 않고 이미 있는 Chrome으로 렌더링한다.
